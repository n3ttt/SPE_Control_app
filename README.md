# SPE Expert 1.5K-FA Control Panel

A friendlier remote control panel for the SPE Expert 1.5K-FA linear amplifier: gauges, plain-English alerts, one-click band and power-level selection, a 2-minute history graph and an event log.

## Use

1. Connect the amp by USB (FTDI driver installed, so it appears as a COM port).
2. Open `expert-control.html` in Chrome or Edge.
3. Click **Connect amplifier** and choose the "USB Serial Port" (115200 baud).

Click **Demo mode** to try it without the amp.

Keyboard: `O` operate/standby · `P` power level · `A` antenna · `T` tune · `I` input · `←`/`→` band.

> Not yet verified against the real amplifier. The protocol details were written from memory of SPE's programmer's guide.
